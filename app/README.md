# Smart Store

A high-performance Flutter POS and Inventory management application with a cloud-native **Supabase** backend.

## 🚀 Getting Started

This project is now fully self-contained on the cloud. To run the app, simply use:

```powershell
flutter run -d chrome
```

*No local backend server is required.*

## 🛠️ Technology Stack
- **Frontend**: Flutter (3.x) with BLoC state management and GoRouter.
- **Backend**: Supabase (PostgreSQL, Authentication, and Storage).
- **Styling**: Google Fonts (Inter, Manrope) with a custom design system.

## 📁 Key Features
- **Dashboard**: Real-time sales performance analytics.
- **Inventory**: Full CRUD with cloud image uploads and low-stock alerts.
- **Sales Terminal**: Multi-item invoice generation with PDF printing and sharing.
- **Authentication**: Role-based access control (RBAC).
